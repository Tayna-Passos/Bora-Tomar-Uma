# 🍻 Bora Tomar Uma?

[cite_start]O **Bora Tomar Uma?** é um aplicativo de delivery especializado na comercialização e entrega expressa de bebidas alcoólicas e não alcoólicas[cite: 2, 55]. [cite_start]O sistema foi projetado para solucionar gargalos logísticos, como a entrega de "última milha", oferecendo agilidade e conveniência para usuários em São Paulo[cite: 6, 56, 62].

🚀 **Acesse o sistema:** [https://tayna.free.nf/?i=1](https://tayna.free.nf/?i=1)

## 🛠️ Tecnologias e Infraestrutura

[cite_start]O projeto utiliza uma stack robusta focada em escalabilidade, segurança e alta disponibilidade[cite: 81, 114].

* [cite_start]**Linguagem:** PHP (Backend & Lógica)[cite: 201, 202].
* [cite_start]**Banco de Dados:** MySQL 8.0[cite: 122, 198].

## 📋 Funcionalidades (CRUD)

## 🗄️ Estrutura do Banco de Dados

[cite_start]A arquitetura de dados segue normas rigorosas de normalização e integridade[cite: 122, 172]:

* [cite_start]**Usuários x Pedidos:** Relação 1:N (Um usuário pode realizar vários pedidos)[cite: 175].
* [cite_start]**Pedidos x Entregas:** Relação 1:1 (Um pedido está vinculado a uma única entrega)[cite: 177].
* [cite_start]**Produtos x Pedidos:** Relação N:M (Produtos podem estar presentes em múltiplos pedidos)[cite: 190].
* [cite_start]**Pedidos x Pagamentos:** Relação 1:1[cite: 195].
